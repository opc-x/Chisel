# JobSniper

Personal job radar and role-matching workspace — aggregates roles across channels, builds structured job profiles, and scores fit against custom criteria.

🌐 **Live:** [jobsniper.opc-x.org](https://jobsniper.opc-x.org)

## Stack

- **Framework:** Next.js 15 (App Router, Server Actions)
- **Language:** TypeScript (strict)
- **Database:** Neon Serverless PostgreSQL + Drizzle ORM
- **Styling:** Tailwind CSS + PWA support
